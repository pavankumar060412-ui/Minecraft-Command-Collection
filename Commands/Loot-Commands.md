# Minecraft Loot Commands

A collection of commands used to generate, give, and manage loot in Minecraft.

# What Is The Loot Command?

The `/loot` command allows players and map creators to generate loot from:
- Loot tables
- Mobs
- Blocks
- Fishing
- Containers

It is useful for:
- Custom rewards
- Adventure maps
- RPG systems
- Minigames
