# Minecraft Redstone Tutorial

A beginner-to-advanced guide for learning Minecraft redstone systems.

# What Is Redstone?

Redstone is Minecraft's electricity-like system that allows players to create machines, automation, and complex builds.

Redstone is used for:

- Automatic farms
- Doors
- Traps
- Machines
- Clocks
- Sorting systems
- Advanced creations

---

# Basic Redstone Components

## Redstone Dust

Redstone dust carries power between components.

Uses:

- Connecting circuits
- Transmitting signals
- Activating devices

---

## Redstone Torch

A redstone torch provides power and can invert signals.

Uses:

- Logic circuits
- Doors
- Automatic systems

---

## Lever

A lever creates a constant signal.

Uses:

- Turning machines on/off
- Hidden bases
- Control systems

---

## Button

A button creates a short pulse.

Uses:

- Doors
- Commands
- Traps

---

## Pressure Plate

Activates when something stands on it.

Uses:

- Automatic doors
- Mob traps
- Security systems

---

# Redstone Power

A redstone signal has a maximum strength of:

```text
15 blocks
```

After this distance, the signal needs a repeater.

---

# Redstone Repeater

Repeaters are used to:

- Extend signals
- Add delays
- Control timing

Example:

```text
Power → Repeater → Power
```

---

# Redstone Comparator

Comparators are used for:

- Measuring containers
- Comparing signals
- Advanced circuits

Uses:

- Storage systems
- Item detectors
- Machines

---

# Pistons

## Normal Piston

Pushes blocks.

Used for:

- Doors
- Machines
- Farms

---

## Sticky Piston

Pushes and pulls blocks.

Used for:

- Hidden doors
- Moving structures

---

# Observers

Observers detect block changes.

Example:

```text
Block Change
      ↓
 Observer
      ↓
 Signal
```

Uses:

- Automatic farms
- Machines
- Detection systems

---

# Basic Redstone Builds

## Automatic Door

Requires:

- Pistons
- Redstone dust
- Pressure plate/button

System:

```text
Input
 ↓
Redstone Signal
 ↓
Pistons Move
 ↓
Door Opens
```

---

## Redstone Lamp System

Components:

- Redstone lamp
- Lever
- Redstone dust

Use:

```text
Lever → Redstone → Lamp
```

---

# Redstone Clocks

A redstone clock creates repeated signals.

Used for:

- Automatic farms
- Machines
- Timers

Types:

- Hopper clock
- Observer clock
- Repeater clock

---

# Automatic Farm Systems

Redstone farms use:

- Observers
- Pistons
- Water
- Hoppers

Examples:

- Sugar cane farm
- Pumpkin farm
- Melon farm
- Bamboo farm

---

# Hopper Systems

Hoppers move items automatically.

Uses:

- Storage
- Sorting
- Collection systems

Example:

```text
Chest
 ↓
Hopper
 ↓
Chest
```

---

# Command Block Redstone

Redstone can activate commands.

Example:

```mcfunction
/give @p diamond
```

Activated by:

- Buttons
- Levers
- Pressure plates
