# Mining Methods

## Branch Mining

A safe method for finding ores.

Pattern:

```text
Main Tunnel
    |
Side Tunnels
```

Advantages:

- Efficient
- Safe
- Finds many ores

---

# Strip Mining

Mining large areas in straight lines.

Useful for:

- Large resource collection

---

# Cave Mining

Exploring natural caves.

Advantages:

- Easy resources
- Less digging

Risks:

- Mobs
- Lava

---

# Safe Mining Rules

## Never Dig Straight Down

You can fall into:

- Lava
- Caves
- Deep drops

---

## Carry A Water Bucket

Useful for:

- Lava
- Falling
- Emergency escapes

---

## Use Torches

Torches:

- Light caves
- Prevent mob spawning
- Mark paths

---

# Diamond Mining Tips

For diamonds:

1. Go to Y -59.
2. Create tunnels.
3. Use branch mining.
4. Watch for lava.
5. Use Fortune III when possible.
