# Minecraft Enchanting Tutorial

A complete step-by-step guide to creating powerful enchanted gear.

# What Is Enchanting?

Enchanting is a system that adds special abilities to items.

You can enchant:

- Tools
- Weapons
- Armor
- Books
- Bows
- Tridents

---

# What You Need

To enchant items, you need:

- Enchanting Table
- Lapis Lazuli
- Experience Levels
- Bookshelves

---

# Crafting An Enchanting Table

Required:

```text
1 Book
2 Diamonds
4 Obsidian
```

Recipe:

```text
Book
Diamond Obsidian Diamond
Obsidian Obsidian Obsidian
```

---

# Setting Up An Enchanting Room

For maximum enchantments:

Use:

```text
15 Bookshelves
```

Placement:

```text
Bookshelves

  1 block gap

Enchanting Table
```

---

# Getting Experience

Ways to get XP:

- Mining ores
- Killing mobs
- Smelting
- Fishing
- Trading
- XP farms

---

# Enchanting Process

Steps:

1. Place enchanting table.
2. Put item inside.
3. Add lapis lazuli.
4. Select enchantment.
5. Collect enchanted item.

---

# Enchanting Books

Books can store enchantments.

Advantages:

- Save enchantments
- Combine later
- Apply to specific items

---

# Using Anvils

Anvils combine:

- Items
- Enchanted books
- Repair materials

Example:

```text
Diamond Sword + Sharpness V Book
=
Sharpness V Sword
```

# Villager Enchanting Method

Librarians are the best way to get specific books.

Steps:

1. Place a lectern.
2. Check the trade.
3. Break the lectern if unwanted.
4. Repeat.
5. Lock the trade when found.

---

# Mending

Mending is one of the most valuable enchantments.

It repairs items using:

```text
Experience Orbs
```

Obtained from:

- Villager trades
- Loot
- Fishing

---

# Enchanting Tips

- Get Mending early.
- Use villagers for rare books.
- Combine books carefully.
- Keep XP farms.
- Repair valuable items with Mending.
